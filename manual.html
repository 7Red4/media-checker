media-checker

Chrome 擴充功能（Manifest V3）：在任何網頁上把圖片或影片開進燈箱，自由縮放、拖曳、旋轉。

安裝 開啟燈箱 燈箱操作 複製網址 能偵測什麼 載入失敗時 已知限制 權限與隱私 開發與測試

安裝

  1. 開啟 chrome://extensions，打開右上角的「開發人員模式」。
  2. 點「載入未封裝項目」，選擇 media-checker 資料夾。
  3. 完成。已開啟的分頁會自動生效，不需要重新整理。
要在本機 file:// 頁面使用，請到擴充功能的「詳細資料」開啟「允許存取檔案網址」。

開啟燈箱

把游標移到圖片或影片上，用以下任一種方式：

方式說明
右鍵選單 → media-check一般用法。
Alt + 右鍵直接開啟，網站停用右鍵選單時也有效。

游標位置找不到媒體時，會顯示「這個位置找不到圖片或影片」。

燈箱操作

操作效果
滾輪以游標為中心縮放
左鍵拖曳移動媒體
在右下角區塊內滾動滾輪旋轉；按住 Shift 微調
空白鍵、點擊影片播放／暫停
Esc有縮放、旋轉或移動時先復原；已是原狀時關閉燈箱

iframe 裡的媒體會開在整個分頁的燈箱中，不會被限制在 iframe 的小框框裡；原本的影片會先暫停，避免兩份聲音同時播放。

複製目前網址

按 Alt + C 會複製目前分頁的網址，成功時顯示「已複製網址連結」。

  • 焦點需要在網頁內容上；焦點在網址列或 Chrome 不允許擴充功能的頁面時不會作用。
  • 焦點在 iframe 內時，複製的仍是分頁本身的網址。

能偵測什麼

media-checker 依游標座標往下找媒體，而不是看滑鼠點到哪個元素，所以被透明遮罩蓋住的圖片也找得到。

元素

  • img（srcset 取最高解析度、<picture>、lazy-load 的 data-src）
  • video、canvas、inline svg、SVG <image>、input[type=image]、object／embed

CSS 圖片

  • background-image、::before／::after、content: url()、mask-image、border-image、image-set()

難搞的情況

  • pointer-events: none、透明遮罩、spacer.gif 之類的佔位圖、疊在媒體上的小圖示
  • open 與 closed shadow DOM、visibility: hidden、inert
  • 同來源與跨來源 iframe，包含 pointer-events: none 的 iframe 與蓋在媒體上的透明 iframe

載入失敗時的退回順序

圖片

  1. 直接載入原網址。
  2. 由擴充功能背景頁帶著 cookie 重新抓取（處理需要登入或防盜連的圖片）。
  3. 拷貝頁面上已解碼的畫面。

影片

  1. 建立新的 video 元素載入。
  2. 鏡像原影片的畫面（MSE、串流），控制列直接操作原影片。
  3. 擷取目前畫面的截圖。
  4. 顯示 poster 圖片。

iframe 內的媒體若在頂層載入不到，改在媒體所在的 iframe 內開啟。

已知限制

  • chrome:// 頁面、線上應用程式商店、內建 PDF 檢視器：Chrome 不允許擴充功能注入。
  • DRM 影片（Widevine 等）無法複製或鏡像，畫面可能全黑。
  • 未開啟 preserveDrawingBuffer 的 WebGL canvas，擷取結果可能是空白。
  • canvas 顯示的是開啟當下的靜態畫面。
  • 跨來源且被污染（tainted）的 canvas 無法傳到頂層，會在所在的 iframe 內開啟。

權限與隱私

權限用途
contextMenus右鍵選單的 media-check 項目
scripting對安裝前就已開啟的分頁補注入腳本
<all_urls>在所有網站與 iframe 中偵測媒體，並在必要時重新抓取圖片

擴充功能沒有任何遙測或外部伺服器。唯一的網路請求是「重新抓取圖片」：背景頁會帶著你在該網站的 cookie 去抓頁面上原本就有的那張圖，只接受 http(s) 與 image/* 回應、上限 40 MB，結果只在本機燈箱中顯示。

跨 frame 的探測訊息使用由背景頁核發、5 秒內有效的一次性憑證，網頁無法偽造。

開發與測試

檔案結構

manifest.json
background.js        右鍵選單、frame 間訊息轉送、圖片重抓
content/detect.js    座標 → 媒體
content/lightbox.js  燈箱 UI 與互動
content/main.js      事件攔截、跨 frame 探測
icons/               圖示（SVG 原稿與 PNG）
test/                手動測試頁

手動測試

跨來源案例需要 HTTP 伺服器，且必須從 localhost 開啟（測試頁會用 127.0.0.1 載入跨來源 iframe）：

npx http-server test -p 8080

接著開啟 http://localhost:8080/index.html，在每個測試案例上用 Alt + 右鍵試試看。

修改程式後，在 chrome://extensions 按擴充功能的重新載入鈕即可，舊腳本會自動卸載，不必重新整理網頁。
